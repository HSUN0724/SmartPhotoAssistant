# V6.2 手機公開展示與場景選單修正

本版由穩定的 `v6.1-photo-exposure-fix` 複製建立，沒有修改原版。

## 本次修改

- 新增 `start_public.ps1`，可用 Cloudflare Quick Tunnel 產生臨時 HTTPS 網址。
- 手機和電腦不在同一個 Wi-Fi 時，也能在展示期間使用網站。
- 拍照分析、攝影建議及曝光模擬的場景選單預設改為「請選擇拍攝情境」。
- 從完整流程帶入既有場景時，仍會自動保留該場景。
- 手機直接拍照後，前端會檢查 JPG 是否包含 EXIF 區段。
- 直接拍照檔案缺少 EXIF 時，頁面會明確說明手機或瀏覽器可能已移除資訊。
- 後端可保留部分 EXIF；只有 ISO、光圈、快門都完整時才執行曝光比較。
- 手機沒有提供 EXIF 時仍可使用 Gemini 畫面分析，不會產生虛構的拍攝參數。

## 建議測試

1. 直接開啟拍照分析頁，確認場景顯示「請選擇拍攝情境」。
2. 只選照片而未選場景，確認不能送出。
3. 手機直接拍照；若檔案無 EXIF，確認上傳前及結果頁都有提示。
4. 從相簿選擇含完整 EXIF 的 JPG，確認 ISO、光圈與快門仍可分析。
5. 照片分析帶入攝影建議後，確認已選場景會保留。
6. 直接開啟曝光模擬，確認未選場景前參數與 AI 按鈕不可操作。
7. 執行 `start_public.ps1`，以手機行動網路開啟產生的 HTTPS 網址。
