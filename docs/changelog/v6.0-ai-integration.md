# Complete V6 AI Integrated 整合說明

這個資料夾是由 `complete-v5` 複製後製作的獨立新版，不會覆蓋或修改原本的 V5。

## 本版完成的四段流程

1. 攝影建議與曝光模擬共用 `recommendations.py` 的 21 種情境參數。
2. 照片分析結果可帶到攝影建議頁，包括 EXIF、曝光差異、規則分析與已產生的 Gemini 照片建議。
3. 攝影建議可把同一個情境、ISO、光圈與快門直接帶入曝光模擬。
4. 攝影建議與曝光模擬都可使用 Gemini 產生自然語言解釋；沒有金鑰或連線失敗時會改用內建解釋。

## 建議展示流程

1. 開啟「拍照分析」，選擇情境並上傳 JPG。
2. 查看 EXIF、曝光與智慧情境分析；需要時按「產生 AI 攝影建議」。
3. 按「將分析結果帶入攝影建議」。
4. 在攝影建議頁確認照片摘要與推薦參數，可按「產生 AI 解釋」。
5. 按「將這組參數帶入曝光模擬」。
6. 在曝光頁調整參數，分別觀察「曝光量」與「情境參數適用性」。
7. 將運動情境快門改為 `1/125`，可展示即使曝光量接近，快門仍不適合凝結動作。

## 啟動方式

```powershell
cd .\SmartPhotoAssistant-complete-v6-ai-integrated
py -m pip install -r requirements.txt
py app.py
```

若 V5 已有 `.env`，請複製一份到這個新版資料夾。不要把真實金鑰放進繳交 ZIP。

## 本版刻意不處理的項目

- 不加入天氣資訊。
- 不修改既有三站攝影文章爬蟲來源。
- 不把曝光補償直接加入 M 模式曝光公式；目前只顯示提示。
