# Smart Photo Assistant v6.1 修正說明

本版本由 `complete-v6-ai-integrated` 複製修改，不會覆蓋原版本。

## 本次修正

- 照片分析會另外保存曝光模擬可使用的 ISO、光圈與快門純數值。
- 從照片分析進入攝影建議後，曝光按鈕會優先傳送照片原始 EXIF，而不是情境推薦值。
- 曝光頁新增「恢復照片原始參數」與「改用此情境推薦參數」兩顆按鈕。
- 切換拍攝情境只更換比較標準，不會自動覆蓋目前的 ISO、光圈和快門。
- 若照片的 `f/3.6`、`1/180` 等數值不在原選單中，會新增「照片原始」選項並保留精確值。
- 沒有完整 EXIF 時，仍會改用情境推薦參數，且不顯示無法使用的「恢復照片原始參數」按鈕。
- JavaScript 加入 `v=6.1` 版本標記，避免瀏覽器繼續使用舊快取。

## 正確測試流程

1. 上傳一張含完整 EXIF 的 JPG 照片。
2. 記下照片分析顯示的 ISO、光圈與快門。
3. 按「將分析結果帶入攝影建議」。
4. 在攝影建議頁按「將照片原始參數帶入曝光模擬」。
5. 曝光頁的三個選單應顯示照片原始值。
6. 切換拍攝情境，三個選單不應自行改變。
7. 按「改用此情境推薦參數」後才切換成推薦值。
8. 按「恢復照片原始參數」可回到照片 EXIF。

若剛測試過舊版本，請停止伺服器、從這個 v6.1 資料夾重新執行 `py app.py`，再重新走一次照片上傳流程。舊工作階段資料不包含 v6.1 新增的標準化欄位。
